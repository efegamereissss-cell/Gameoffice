# FX-GX GAME (GameOffice) 🎮

FX-GX GAME resmi indirme ve tanıtım sayfası.

## 🚀 Özellikler
- **Hızlı ve Modern Tasarım:** Saf HTML5, CSS3 ve JavaScript (sıfır bağımlılık).
- **Tek Tıkla İndirme:** FX-OFFICE doğrudan indirme entegrasyonu.
- **Vercel Uyumlu:** Vercel üzerinde sıfır yapılandırma (zero-config) ile doğrudan çalışır.

## 🌐 Vercel Üzerinde Yayınlama
1. [Vercel Dashboard](https://vercel.com/dashboard) adresine gidin.
2. **Add New...** > **Project** seçin.
3. GitHub hesabınızı bağlayıp `GameOffice` deposunu içe aktarın (Import).
4. Herhangi bir ayar değiştirmeden doğrudan **Deploy** butonuna tıklayın.

## 💻 Yerel Çalıştırma
Projeyi bilgisayarınızda çalıştırmak için:
- `BASLAT.bat` dosyasına çift tıklayabilir veya
- `index.html` dosyasını doğrudan tarayıcınızda açabilirsiniz.
